# <h2 dir="rtl">

📘 PHP بالعربي
  </h2>

مشروع **تعلّم لغة PHP بالعربية** 🎓  
هدفه توفير محتوى تعليمي منظّم وسهل الاستخدام للمبتدئين والمطورين باللغة العربية، مع أمثلة عملية ودروس مبسطة.

---

## ✨ المميزات
- شرح مبسط لمفاهيم لغة **PHP** خطوة بخطوة.
- أقسام ودروس منظمة (أساسيات، متغيرات، دوال...).
- أمثلة عملية مع شيفرات جاهزة للتجربة.
- قاعدة بيانات قابلة للتوسع لإضافة تقنيات أخرى مستقبلًا.

---

## 🛠️ التقنيات المستخدمة
- **Laravel** — إطار العمل الأساسي.
- **MySQL** — قاعدة البيانات.
- **Blade** — واجهة العرض.
- **TailwindCSS / Bootstrap** — لتصميم الواجهة.

---

## 📂 هيكل قاعدة البيانات
- **technologies** → التقنيات (مثال: PHP, JavaScript...)
- **sections** → أقسام داخل كل تقنية.
- **lessons** → الدروس التعليمية.
- **builtin_functions** → الدوال المدمجة الجاهزة.
